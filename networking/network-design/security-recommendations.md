# Security Recommendations for Corporate Office Network

## 1. Departmental Network Segmentation

Each department should operate in a separate VLAN and subnet.

**Reason:** This reduces unnecessary communication between departments and limits the spread of attacks across the network.

## 2. Firewall Rules

Configure firewall rules to control incoming and outgoing network traffic.

Only authorized traffic should be allowed between departmental networks and internal servers.

**Reason:** Firewall rules help prevent unauthorized access and reduce network security risks.

## 3. Secure VPN Authentication

Remote employees should access internal resources through a secure VPN connection.

Use strong authentication, preferably multi-factor authentication (MFA).

**Reason:** VPN encryption protects data during transmission, while authentication ensures that only authorized users can connect.

## 4. Server Access Restrictions

The server room should be isolated from ordinary employee networks.

Only authorized departments and administrators should access specific server services.

**Reason:** This protects sensitive company information and reduces the risk of unauthorized access.

## 5. Network Monitoring

Monitor network traffic, firewall logs, and suspicious connection attempts.

Use security monitoring tools to identify unusual network activities.

**Reason:** Continuous monitoring helps detect potential attacks and security incidents.

## 6. Secure Wi-Fi Configuration

Use WPA2-AES or WPA3 encryption and strong Wi-Fi passwords.

Create separate wireless networks for employees and guests.

**Reason:** Secure wireless configuration helps prevent unauthorized users from accessing the internal company network.

## Conclusion

Implementing network segmentation, firewall rules, VPN authentication, server restrictions, network monitoring, and secure Wi-Fi configuration helps create a more secure and manageable corporate network.
