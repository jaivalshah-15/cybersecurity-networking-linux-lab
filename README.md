# Cybersecurity Networking & Linux Lab

A hands-on cybersecurity fundamentals project focused on networking, Linux system administration, network troubleshooting, and basic security investigation.

This project demonstrates practical knowledge through real command execution, network design, subnetting calculations, Linux file management, permission configuration, and log analysis.

## Project Objectives

- Understand IPv4 addressing and subnetting.
- Design a segmented corporate office network.
- Perform network connectivity and DNS troubleshooting.
- Explore Linux filesystem architecture.
- Manage files, directories, permissions, and ownership.
- Investigate application logs and identify errors.
- Document practical cybersecurity exercises.

## Practical Tasks

### 1. Office Network Design & Subnetting
- Corporate network design for a four-floor office.
- IPv4 subnetting and CIDR calculations.
- IP address allocation.
- Network capacity analysis.
- Network segmentation and security recommendations.

### 2. Networking Concepts & Troubleshooting
- Private and public IP addressing.
- Subnetting and default gateways.
- DNS and DHCP.
- TCP vs UDP.
- VPN and network troubleshooting.

### 3. Practical Networking Commands
- Network configuration inspection.
- Connectivity testing using ping.
- DNS investigation using nslookup.
- Network route analysis using traceroute.

### 4. Linux Filesystem & Commands
- Linux filesystem navigation.
- File and directory management.
- Working with absolute and relative paths.
- File creation, copying, moving, and renaming.

### 5. Linux Permissions & File Management
- Understanding Linux permissions.
- chmod and chown.
- Numeric and symbolic permissions.
- File searching and inspection.
- Linux access control fundamentals.

### 6. Linux Investigation Challenge
- Simulated IT environment.
- Application log investigation.
- Error identification and analysis.
- File backups.
- Permission verification.
- Investigation documentation.
